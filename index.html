About multiplayer and private rooms

How multiplayer works

Players connect to a Cloudflare Worker over WebSockets. The Worker relays game messages; the host's browser deals and validates actions. No Firebase is used. Cloudflare's free plan has daily usage limits.

Friends-only trust model: the host can see and control the game state. Do not use this for valuable stakes.
